## Usage

```jsx
import { Command, Portal, useCommandCollection } from "@chakra-ui/react"
```

```jsx
<Command.Provider>
  <Command.Dialog>
    <Command.DialogTrigger />
    <Portal>
      <Command.DialogBackdrop />
      <Command.DialogContent>
        <Command.Root>
          <Command.Label />
          <Command.Control>
            <Command.Indicator />
            <Command.Input />
            <Command.ClearTrigger />
          </Command.Control>
          <Command.List>
            <Command.Loading />
            <Command.ItemGroup>
              <Command.ItemGroupLabel />
              <Command.Item>
                <Command.ItemText />
                <Command.ItemCommand />
              </Command.Item>
            </Command.ItemGroup>
            <Command.Separator />
            <Command.Empty />
          </Command.List>
          <Command.Footer />
        </Command.Root>
      </Command.DialogContent>
    </Portal>
  </Command.Dialog>
</Command.Provider>
```

Items are data. `useCommandCollection` ranks them as you type, and
`Command.Provider` shares the result with the dialog and the root.

```tsx
const command = useCommandCollection({ initialItems: commands })

<Command.Provider value={command}>
  <Command.Dialog>
    <Portal>
      <Command.DialogBackdrop />
      <Command.DialogContent>
        <Command.Root>{/* ... */}</Command.Root>
      </Command.DialogContent>
    </Portal>
  </Command.Dialog>
</Command.Provider>
```

- Selecting an item runs its `onSelect` and closes the dialog. Set
  `closeOnSelect: false` on the item, or on `Root`, to keep it open.
- The dialog clears the query after it closes.
- `Command.DialogBackdrop` is optional.
- Set `disabled: true` on an item to show it without letting it run.
- There's no built-in shortcut to open the dialog. Bind `⌘K` with the tool your
  app already uses, as in [Hotkeys](#hotkeys).

Command runs actions and keeps no selected value. For a picker, use
[Combobox](/docs/components/combobox) or [Listbox](/docs/components/listbox).

### Coming from cmdk

In cmdk, items are elements that cmdk filters in the DOM. Here, items are data
that `useCommandCollection` ranks.

| cmdk                            | Chakra UI                                          |
| ------------------------------- | -------------------------------------------------- |
| `<Command>`                     | `<Command.Root>` with `useCommandCollection`       |
| `<Command.Dialog>`              | `<Command.Dialog>` + `<Command.DialogContent>`     |
| `<Command.Input>`               | `<Command.Input>`                                  |
| `<Command.List>`                | `<Command.List>`                                   |
| `<Command.Item onSelect={fn}>`  | `{ label, value, onSelect: fn }` in `initialItems` |
| `<Command.Group heading="...">` | `<Command.ItemGroup>` + `<Command.ItemGroupLabel>` |
| `<Command.Empty>`               | `<Command.Empty>`                                  |
| `shouldFilter={false}`          | `filter: null`                                     |

### Inline

Render `Command.Root` without a dialog and pass the collection with the
`command` prop. Add a `Command.Label` to name the search, visually hidden if
needed. In a dialog, the hidden title from `Command.DialogContent` names it
instead.

Settings. Keyword matches rank just below label matches.

### Highlight Matches

Set `highlight` on `ItemText` to bold the matched characters, including fuzzy
and camelCase matches.


### Bring Your Own Data

To fetch with your own data layer, such as TanStack Query, control the query and
pass the results in. Set `filter: null` so server results show as returned.

```tsx
const [query, setQuery] = useState("")
const people = useQuery({
  queryKey: ["people", query],
  queryFn: () => searchPeople(query),
})

const command = useCommandCollection({
  initialItems: people.data ?? [],
  query,
  onQueryChange: setQuery,
  filter: null,
})

<Command.Root command={command} loading={people.isFetching}>
  {/* ... */}
</Command.Root>
```

### Nested

Use `useCommandPageCollection` for nested pages. It works like
`useCommandCollection`, and an item with a `parent` lives on that item's page.

```tsx
const command = useCommandPageCollection({
  initialItems: [
    { label: "Change status...", value: "status" },
    { label: "Done", value: "status:done", parent: "status" },
  ],
  deepSearch: true,
})

<Command.Provider value={command}>
  <Command.Dialog>
    <Portal>
      <Command.DialogBackdrop />
      <Command.DialogContent>
        <Command.Root>
          <Command.Input onKeyDown={command.onInputKeyDown} />
          {/* ... */}
        </Command.Root>
      </Command.DialogContent>
    </Portal>
  </Command.Dialog>
</Command.Provider>
```

- Selecting an item with children opens its page.
- Escape goes back to the previous page, then closes the dialog.
- Backspace on an empty input goes up a page. Pass `onInputKeyDown` to the input
  for this.
- Going back restores the query and highlights the item you came from.
- `command.pages` is the trail of open pages, for a breadcrumb.
- With `deepSearch`, a query also matches items in nested pages.
  `command.getPath(item)` returns where a match lives.
- To open a page directly, such as from a shortcut, call
  `command.reset("status")` before opening the dialog. Escape then closes it.

### Virtualized

Virtualize the list for large datasets. Pass a deferred copy of the query as
`filterQuery` so typing stays responsive. Enter still runs the top match for
what you typed.

```tsx
const [query, setQuery] = useState("")
const command = useCommandCollection({
  initialItems,
  query,
  onQueryChange: setQuery,
  filterQuery: useDeferredValue(query),
})
```
