## Usage

```jsx
import { Portal, Tour, useTour } from "@chakra-ui/react"
```

```jsx
const tour = useTour({ steps })

<Tour.Root tour={tour}>
  <Portal>
    <Tour.Backdrop />
    <Tour.Spotlight />
    <Tour.Positioner>
      <Tour.Content>
        <Tour.Arrow>
          <Tour.ArrowTip />
        </Tour.Arrow>
        <Tour.CloseTrigger />
        <Tour.Title />
        <Tour.Description />
        <Tour.Control>
          <Tour.ProgressText />
          <Tour.Actions>
            {(actions) =>
              actions.map((action) => (
                <Tour.ActionTrigger key={action.label} action={action}>
                  {action.label}
                </Tour.ActionTrigger>
              ))
            }
          </Tour.Actions>
        </Tour.Control>
      </Tour.Content>
    </Tour.Positioner>
  </Portal>
</Tour.Root>
```

## Examples

### Step Types

Each step can be one of four types:

- `dialog`: centered modal, not attached to any element
- `tooltip`: points to a target element
- `floating`: pinned to a corner of the screen, no target
- `wait`: invisible step that pauses until something happens

## Patterns

### Wait for an Action

Move on only when the user does what the step asks. Use the step's `effect` with
`waitForEvent` or `waitForElementValue`, and call `next()` when it resolves.

<ExampleTabs name="tour-wait-for-action" />

### Branching

A custom action receives `next`, `prev`, `dismiss`, `skip` and `goto`. Use
`goto` to send people down different paths.

<ExampleTabs name="tour-branching" />

### Checklist

Start the tour at a specific step with `tour.start(stepId)`, and mark items done
from `onStatusChange`.

<ExampleTabs name="tour-with-checklist" />

### Resume Later

where the user left off.

## Keyboard

Arrow keys move between steps and Escape closes the tour. Turn arrow key
navigation off with `keyboardNavigation: false`, and Escape with
`closeOnEscape: false`.

## Callbacks

`onStepChange` fires when the step changes. `onStatusChange` reports `started`,
`completed`, `dismissed`, `skipped` and `not-found`.

## Configuration

These options can be passed to `useTour`:

| Option                   | Type      | Default | Description                                         |
| ------------------------ | --------- | ------- | --------------------------------------------------- |
| `closeOnEscape`          | `boolean` | `true`  | Close the tour when pressing Escape                 |
| `closeOnInteractOutside` | `boolean` | `true`  | Close when clicking outside tour content            |
| `preventInteraction`     | `boolean` | `false` | Block page interaction while tour is active         |
| `keyboardNavigation`     | `boolean` | `true`  | Navigate steps with arrow keys                      |
| `spotlightOffset`        | `object`  | -       | Padding around spotlight `{ x: number, y: number }` |
| `spotlightRadius`        | `number`  | -       | Border radius of the spotlight in pixels            |

Per-step options:

| Option      | Type       | Default | Description                                                           |
| ----------- | ---------- | ------- | --------------------------------------------------------------------- |
| `type`      | `string`   | -       | `dialog`, `tooltip`, `floating` or `wait`                             |
| `target`    | `function` | -       | Returns the element to highlight                                      |
| `actions`   | `array`    | -       | Buttons for the step: `next`, `prev`, `dismiss`, `skip` or a function |
| `effect`    | `function` | -       | Runs when the step starts; receives `show`, `next`, `goto`, `update`  |
| `arrow`     | `boolean`  | `true`  | Show arrow on tooltip steps                                           |
| `backdrop`  | `boolean`  | `true`  | Show backdrop for this step                                           |
| `placement` | `string`   | -       | Tooltip placement relative to target                                  |
| `offset`    | `object`   | -       | Distance between content and target `{ mainAxis, crossAxis }`         |
| `meta`      | `object`   | -       | Arbitrary metadata for custom rendering                               |
