## Usage

```jsx
import { Portal, Tour, useTour } from "@chakra-ui/react"
```

```jsx
const tour = useTour({ steps })

<Tour.Root tour={tour}>
  <Portal>
    <Tour.Backdrop />
    <Tour.Spotlight />
    <Tour.Positioner>
      <Tour.Content>
        <Tour.Arrow>
          <Tour.ArrowTip />
        </Tour.Arrow>
        <Tour.CloseTrigger />
        <Tour.Title />
        <Tour.Description />
        <Tour.Control>
          <Tour.ProgressText />
          <Tour.Actions>
            {(actions) =>
              actions.map((action) => (
                <Tour.ActionTrigger key={action.label} action={action}>
                  {action.label}
                </Tour.ActionTrigger>
              ))
            }
          </Tour.Actions>
        </Tour.Control>
      </Tour.Content>
    </Tour.Positioner>
  </Portal>
</Tour.Root>
```

## Closed Component

For ease of use, create a closed component composition for the `Tour` component.
It renders the full anatomy, composes `Button` and `CloseButton`, and respects
each step's `backdrop` and `arrow` options.

```sh
npx @chakra-ui/cli snippet add tour
```

```jsx
import { useTour } from "@chakra-ui/react"
import { Tour } from "@/components/ui/tour"

```

## Examples

### Step Types

Each step can be one of four types:

- `dialog` - centered modal, not attached to any element
- `tooltip` - points to a specific target element
- `floating` - fixed position on screen, no target
- `wait` - invisible step that pauses until a condition is met

<ExampleTabs name="tour-with-step-types" />

### Placement

Control where the tooltip appears relative to its target using the `placement`
property per step.

<ExampleTabs name="tour-with-placement" />

### Custom Actions

Step actions can use custom functions instead of built-in strings. The function
receives an action map with `next`, `prev`, `dismiss`, `skip`, and `goto`
methods.

<ExampleTabs name="tour-with-custom-actions" />

### Callbacks

Use `onStepChange` and `onStatusChange` callbacks to track tour progress. Status
values include `started`, `completed`, `dismissed`, and `skipped`.

<ExampleTabs name="tour-with-callbacks" />

### Progress

Use `Tour.ProgressText` to display the current step count. Access
`getProgressPercent()` via `Tour.Context` for a percentage value.

<ExampleTabs name="tour-with-progress" />

### Without Backdrop

Set `backdrop: false` on a step to hide the backdrop for that step.

<ExampleTabs name="tour-without-backdrop" />

### Keyboard Navigation

Enable keyboard navigation with `keyboardNavigation: true` on the `useTour`
hook. Users can navigate with arrow keys and close with Escape.

<ExampleTabs name="tour-with-keyboard" />

### Onboarding

An onboarding tour that walks new users through the sidebar, header, and content
area.

<ExampleTabs name="tour-onboarding" />

### Routing

Use step effects to navigate between pages during a tour. Each step's `effect`
function navigates to the correct route and calls `show()` when ready.

<ExampleTabs name="tour-with-routing" />

### Conditional

Use `goto` in custom actions to create branching tours. Users choose a path and

## Configuration

These options can be passed to `useTour`:

| Option                   | Type      | Default | Description                                         |
| ------------------------ | --------- | ------- | --------------------------------------------------- |
| `closeOnEscape`          | `boolean` | `true`  | Close the tour when pressing Escape                 |
| `closeOnInteractOutside` | `boolean` | `true`  | Close when clicking outside tour content            |
| `preventInteraction`     | `boolean` | `false` | Block page interaction while tour is active         |
| `keyboardNavigation`     | `boolean` | `true`  | Navigate steps with arrow keys                      |
| `spotlightOffset`        | `object`  | -       | Padding around spotlight `{ x: number, y: number }` |
| `spotlightRadius`        | `number`  | -       | Border radius of the spotlight in pixels            |

Per-step options:

| Option      | Type       | Default | Description                                                           |
| ----------- | ---------- | ------- | --------------------------------------------------------------------- |
| `type`      | `string`   | -       | `dialog`, `tooltip`, `floating` or `wait`                             |
| `target`    | `function` | -       | Returns the element to highlight                                      |
| `actions`   | `array`    | -       | Buttons for the step: `next`, `prev`, `dismiss`, `skip` or a function |
| `effect`    | `function` | -       | Runs when the step starts; receives `show`, `next`, `goto`, `update`  |
| `arrow`     | `boolean`  | `true`  | Show arrow on tooltip steps                                           |
| `backdrop`  | `boolean`  | `true`  | Show backdrop for this step                                           |
| `placement` | `string`   | -       | Tooltip placement relative to target                                  |
| `offset`    | `object`   | -       | Distance between content and target `{ mainAxis, crossAxis }`         |
| `meta`      | `object`   | -       | Arbitrary metadata for custom rendering                               |
